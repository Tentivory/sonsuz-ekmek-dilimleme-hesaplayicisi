# Sonsuz Ekmek Dilimleme Hesaplayıcısı 🍞∞

## Özet
Bu depo, insanlık tarihinin en kritik sorunlarından birine çözüm getirir: **Bir ekmeği kaç dilime bölebilirsiniz?** Cevap: Sonsuz. Çünkü matematik, fizik ve sağduyu hep birlikte bize yalan söyler.

Bu araç, kuantum belirsizliği, uzay-zaman sürekliliği ve rastgele uzay faktörleri kullanarak ekmek dilim sayısını hesaplar. Sonuç her zaman o kadar büyüktür ki, evrenin tüm ekmek stoku yetmez. Bu yüzden **sonsuz dilim** ilan edilir.

> "Ekmek asla bitmez, sadece dilimlenir. Ve dilimler de asla bitmez."  
> — Absürt Matematik Enstitüsü, Resmi Olmayan Bildiri

## Nasıl Çalışır?
1. Python 3 yükleyin (veya yüklemeyin, zaten çalışmaz diye düşünüyorsunuz).
2. `python ekmek_hesaplayici.py` komutunu çalıştırın.
3. Ekmek uzunluğunu girin (cm).
4. Program, ciddiyetle bekletir, hesaplar ve sonsuz sonucu açıklar.
5. Damga ve imzayı okuyun. Ciddi olun.

## Özellikler
- **Kuantum hesaplama**: Rastgele sayılar kullanır, çünkü kuantum rastgeledir.
- **Sonsuz sonuç garantisi**: Ne kadar küçük ekmek girerseniz girin, dilim sayısı astronomik olur.
- **Abartılı bekleme süreleri**: Hesaplama gerçekten sürer, çünkü ciddiyet şart.
- **Gizli mesajlar**: Kodun içinde saklı şeyler vardır. Merak etmeyin, önemli değil (veya çok önemli).

## Kurulum
```bash
git clone https://github.com/Tentivory/sonsuz-ekmek-dilimleme-hesaplayicisi.git
cd sonsuz-ekmek-dilimleme-hesaplayicisi
python ekmek_hesaplayici.py
```
